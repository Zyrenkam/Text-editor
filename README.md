
# Текстовый редактор

Простое, но функциональное приложение для работы с текстом, разработанное на C# с использованием Windows Forms (WinForms) в рамках дисциплины «Технология системного программирования».

## Описание
Программа представляет собой многооконный текстовый редактор с поддержкой форматирования (RTF). Она позволяет создавать, редактировать, сохранять и печатать документы, а также имеет встроенные инструменты для поиска, замены текста и настройки его внешнего вида.

## Основные возможности

### Работа с файлами
*   **Создание** нового документа.
*   **Открытие** и **сохранение** файлов в формате `.rtf` (с поддержкой форматирования).
*   **Автосохранение**: фоновое сохранение изменений открытого файла каждую минуту.
*   **Многооконность**: возможность открывать несколько независимых окон одновременно.

### Редактирование и форматирование
*   Отмена (Undo) и повтор (Redo) действий.
*   Изменение шрифта, его размера и цвета.
*   Изменение цвета фона текста.
*   Адаптивный интерфейс с центрированием панели инструментов.

### Инструменты
*   **Поиск** текста с подсветкой и подсчетом общего количества вхождений.
*   **Замена** текста (как одиночная, так и замена всех вхождений).
*   **Печать** документа с предварительным просмотром и поддержкой многостраничности.
*   Индикатор состояния документа (галочка — сохранен, крестик — есть несохраненные изменения).

## Как запустить
1. Убедитесь, что у вас установлена **Visual Studio** (с компонентом «Разработка классических приложений .NET»).
2. Скачайте или клонируйте этот репозиторий:
   ```bash
   git clone https://github.com/Zyrenkam/Text-editor.git

3. Откройте файл решения `PR1_2.sln` в Visual Studio.
4. Нажмите **F5** (или «Пуск») для сборки и запуска проекта.

## Технологии
*   **Язык:** C# (.NET Framework)
*   **Платформа:** Windows Forms (WinForms)
*   **Интерфейс:** Кастомная адаптивная верстка, элементы управления (Panel, RichTextBox, ComboBox и др.), ToolTip, Win32 API (для управления Undo).
